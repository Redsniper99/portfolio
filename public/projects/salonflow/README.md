# SalonFlow Project Assets

Upload your screenshots and assets here for the SalonFlow project.

## Recommended Files:
- `thumbnail.png` - Main card thumbnail (16:9 ratio, ~800x450px recommended)
- `hero.png` - Hero image for detail page
- `screenshot-1.png`, `screenshot-2.png`, etc. - Feature screenshots
- `logo.png` - Project logo (if any)

## Usage:
These images will be used in:
- Project card on the main portfolio
- Detailed project page (if created)
- Gallery/carousel of screenshots
